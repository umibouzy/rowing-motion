# エルゴ骨格チェック（試作版 v0.4）

真横から撮ったエルゴの動画から骨格を推定し、ストロークごとの姿勢とタイミングを数値にするWebアプリです。スマホのブラウザだけで動き、インストールは不要です。

## v0.4 の変更点

- 「身長（cm）」の入力欄を追加。身長から縮尺を求め、速度と距離を m/s・m で表示（股関節〜足首を身長の約49%とみなす。誤差の目安±5〜10%）。空欄なら脚の長さを1とした相対値
- シート（腰）とハンドル（手首）の速度を追加：ドライブ／リカバリーのシート最高速度、最高速に達する時点、ハンドル最高速度、シートの移動距離、ドライブ序盤（最初の25%）のハンドル÷シート速度比
- グラフに速度の段を追加し、映像の左下に現在のシート・ハンドル速度を表示
- 表とCSVに速度の項目を追加

## v0.3.2 の変更点

## 公開手順（GitHub Pages）

ROWINGエルゴと同じ方法で公開できます。

1. GitHubで新しいリポジトリを作る（例：`erg-skeleton`）。公開範囲は Public
2. 上の3ファイルをリポジトリの直下にアップロードする（「Add file」→「Upload files」）
3. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして保存
4. 数分後に表示される `https://（ユーザー名）.github.io/erg-skeleton/` を部員に共有する

HTTPSで公開されるので、スマホの「撮影する」ボタンからカメラを起動できます。

## 使い方（部員向け）

1. 撮影ガイドに沿って、真横・腰の高さ・横向きで10〜30秒撮る
2. 「撮影する」または「動画を選ぶ」→「解析する」
3. 再生・コマ送りで骨格と角度を確認する
4. 「骨格つき動画を保存」または「CSVを保存」で書き出し、コーチに送る（スマホでは共有画面が開き、LINEなどに送れます）

## 通信について

- 初回の解析時に、解析ライブラリ（jsDelivr）と骨格モデル（Google）を読み込みます。
- 骨格の推定は端末のブラウザ内で行い、動画そのものは外部に送信しません。
- 検証中に、ライブラリがGoogleのサーバーへログを送ろうとする通信を確認しました。内容は動画ではなく、ライブラリの利用ログとみられます。

## 確認できていること／できていないこと

- 確認済み：PCのChromeで、ライブラリとモデルの読み込みから解析完了までが最後まで動くこと。既知の角度・周期を持つ合成データで、レート・レシオ・体幹角度・膝角度・順番の指標が想定どおり計算されること。
- 確認済み（v0.2）：部員のエルゴ動画1本（約25秒・17spm）で、ストローク検出・各角度・背中の輪郭が映像と合うことを確認。
- 未確認：別の部員・別の服装での背中の輪郭の取れ方、iPhoneでの骨格つき動画の書き出し。

## 注意基準

キャッチ前傾35°、すね0°（垂直越え）は仮の値です。フィニッシュ後傾と「脚が半分伸びた時の体幹の開き」は初期値なし（判定しない）です。画面の「注意基準」でコーチの基準に変更できます（その端末に保存されます）。

## この方法で測れないもの

- カメラ1台の2D推定のため、角度は数度ずれることがあります。前回との比較やストローク間のばらつきを見る用途に向いています。
- 背中の値は骨ではなく体の表面（服の上）の形から出しています。だぶついた服では正しく出ません。フィニッシュ付近は肘で背中が隠れるため、胸の傾きと丸みは出しません。
- 骨盤の傾きそのものは測れません。
- 力・パワーは動画からはわかりません。エルゴモニターの数値を見てください。
